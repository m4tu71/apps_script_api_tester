現在の省略版API仕様

システム構成

ゲーム / テストHTML
        ↓ HTTP POST / GET
Google Apps Script
        ↓
Google Sheets

実装方針

  • Google Apps Script の同一WebアプリURLに対して、POSTでスコア登録、GETでランキング取得を行う。
  • 保存先シート名は game_scores_sheet。
  • シートが存在しない場合はGAS側で自動作成する。
  • ヘッダーもGAS側で自動作成する。
  • 現省略版では playerId / runId は使用しない。
  • 認証・プレイヤー単位の重複制御・自己ベスト管理は行わない。

POST - スコア登録

送信JSON:

{
  "name": "PLAYER",
  "score": 1234,
  "time": 30.5
}
項目型現在の仕様
name string 空文字不可、20文字以内。制御文字不可。先頭が = + - @ の名前は不可。
score number 0以上。現在のサンプル上限は 1,000,000。保存時に整数化。
time number ゲーム内所要時間（分）。0より大きく60以下。小数を許可し、小さいほど高順位。
time は実時間の「秒」ではなく、ゲーム内で経過した「分」を数値で送ります。 例: 30.5 はゲーム内時間で30.5分です。現在は整数になる想定ですが、将来のフレーム単位計測に備えて小数を許可します。

成功レスポンス:

{
  "success": true,
  "message": "score saved"
}

失敗レスポンス例:

{
  "success": false,
  "message": "invalid score"
}

Google Sheets 保存仕様

シート名: game_scores_sheet

列項目内容
Anameランキング表示用の名前
Bscore整数化したスコア
Ctimeゲーム内所要時間（分）。小数可。
DcreatedAtGAS側で new Date() を保存
Estatusactive / hidden
status は新規投稿時に自動で active。 スタッフがGoogle Sheets上のドロップダウンから hidden に変更すると、ランキング対象から除外する想定です。

シート自動初期化

  • game_scores_sheet がなければ自動作成。
  • 空シートなら name / score / time / createdAt / status のヘッダーを自動作成。
  • 1行目を固定。
  • createdAt 列を yyyy/MM/dd HH:mm:ss 表示に設定。
  • status 列に active / hidden のドロップダウンを設定。
  • Spreadsheetのタイムゾーンは Asia/Tokyo を使用。

GET - ランキング取得

  1. status === "active" の記録だけを対象にする。
  2. score の高い順に並べる。
  3. 同スコアなら time の小さい順に並べる。
  4. scoreとtimeも同じなら createdAt の早い順に並べる。
  5. 上位10件を返す。

GETレスポンス例:

[
  {
    "rank": 1,
    "name": "AAA",
    "score": 5000,
    "time": 38.21
  }
]

順位決定ルール

1. score     DESC
2. time      ASC
3. createdAt ASC
